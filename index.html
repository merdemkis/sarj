⚡ Şarj Maliyet Hesaplayıcı

Anlık kontrol kurulumu (bir kez)
  1. github.com → sağ üst profil resmi → Settings → en altta Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Expiration: 1 year. Repository access: Only select repositories → sarj.
  3. Repository permissions: Actions → Read and write; Contents → Read-only.
  4. Generate token'a bas, çıkan anahtarı (github_pat_ ile başlar) buraya yapıştır. Kimseyle paylaşma.
